# version

The `version` command prints the Redacto KMS version:

```shell-session
$ redacto-kms version
Redacto KMS v1.2.3
```

It can also be printed by adding the flags `--version` or `-v` to the `redacto-kms` command:

```shell-session
$ redacto-kms -v
Redacto KMS v1.2.3, built 2022-05-03T08:34:11Z
```
