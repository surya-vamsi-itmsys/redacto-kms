# operator

The `operator` command groups subcommands for operators interacting with Redacto KMS.
Most users will not need to interact with these commands.

## Examples

Initialize a new Redacto KMS cluster:

```shell-session
$ redacto-kms operator init

```

Force a Redacto KMS to resign leadership in a cluster:

```shell-session
$ redacto-kms operator step-down
Success! Stepped down: https://127.0.0.1:8200
```

Rotate Redacto KMS's underlying encryption key:

```shell-session
$ redacto-kms operator rotate
Success! Rotated key

Key Term        2
Install Time    01 Jan 07 12:30 UTC
```

## Usage

```text
Usage: redacto-kms operator <subcommand> [options] [args]

  # ...

Subcommands:
    generate-root    Generates a new root token
    init             Initializes a server
    key-status       Provides information about specific namespace barrier active encryption key
    rekey            Generates new unseal keys (deprecated)
    rotate-keys      Generates new unseal keys
    rotate           Rotates the underlying encryption key
    seal             Seals the Redacto KMS server
    step-down        Forces Redacto KMS to resign active duty
    unseal           Unseals the Redacto KMS server
```

For more information, examples, and usage about a subcommand, click on the name
of the subcommand in the sidebar.
