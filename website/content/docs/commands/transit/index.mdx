# transit

The `transit` command groups subcommands for interacting with Redacto KMS's
[Transit Secrets Engine](../../secrets/transit/index.mdx).

## Syntax

Option flags for a given subcommand are provided after the subcommand, but before the arguments.

## Examples

To [import](import.mdx) keys into a mount via the
[Transit BYOK](../../secrets/transit/index.mdx#bring-your-own-key-byok)
mechanism, use the `redacto-kms transit import <path> <key>` or
`redacto-kms transit import-version <path> <key>` commands:

```
$ redacto-kms transit import transit/keys/test-key @test-key type=rsa-2048
Retrieving transit wrapping key.
Wrapping source key with ephemeral key.
Encrypting ephemeral key with transit wrapping key.
Submitting wrapped key to Redacto KMS transit.
Success!
```
