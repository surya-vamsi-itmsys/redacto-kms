# auth

The `auth` command groups subcommands for interacting with Redacto KMS's auth methods.
Users can list, enable, disable, and get help for different auth methods.

For more information, please see the [auth method
documentation](../../auth/index.mdx) or the [authentication
concepts](../../concepts/auth.mdx) page.

To authenticate to Redacto KMS as a user or machine, use the [`redacto-kms login`](../login.mdx) command instead. This command is for
interacting with the auth methods themselves, not authenticating to Redacto KMS.

## Examples

Enable an auth method:

```shell-session
$ redacto-kms auth enable userpass
Success! Enabled userpass auth method at: userpass/
```

List all auth methods:

```shell-session
$ redacto-kms auth list
Path         Type        Description
----         ----        -----------
token/       token       token based credentials
userpass/    userpass    n/a
```

Get help about how to authenticate to a particular auth method:

```shell-session
$ redacto-kms auth help userpass/
Usage: redacto-kms login -method=userpass [CONFIG K=V...]
# ...
```

Disable an auth method:

```shell-session
$ redacto-kms auth disable userpass/
Success! Disabled the auth method (if it existed) at: userpass/
```

Tune an auth method:

```shell-session
$ redacto-kms auth tune -max-lease-ttl=30m userpass/
Success! Tuned the auth method at: userpass/
```

## Usage

```text
Usage: redacto-kms auth <subcommand> [options] [args]

  # ...

Subcommands:
    disable    Disables an auth method
    enable     Enables a new auth method
    help       Prints usage for an auth method
    list       Lists enabled auth methods
    tune       Tunes an auth method configuration
```

For more information, examples, and usage about a subcommand, click on the name
of the subcommand in the sidebar.
