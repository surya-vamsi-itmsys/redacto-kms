# Redacto KMS Auto-Auth methods

Auto-auth is a mechanism used by Redacto KMS Agent and Redacto KMS Proxy to authenticate
to Redacto KMS in an automatic manner, given a set of parameters allowing the
authentication. Please see the sidebar for available methods and their
usage/configuration.
