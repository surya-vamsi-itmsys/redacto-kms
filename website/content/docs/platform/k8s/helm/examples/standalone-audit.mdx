# Standalone server with audit storage

:::warning

**Important Note:** This chart is not compatible with Helm 2. Please use Helm 3.6+ with this chart.

:::


The below `values.yaml` can be used to set up a single server Redacto KMS cluster with
auditing enabled.

```yaml
server:
  standalone:
    enabled: true
    config: |
      listener "tcp" {
        tls_disable = true
        address = "[::]:8200"
        cluster_address = "[::]:8201"
      }

      storage "pebbledb" {
        path = "/openbao/data"
      }

  service:
    enabled: true

  dataStorage:
    enabled: true
    size: 10Gi
    storageClass: null
    accessMode: ReadWriteOnce

  auditStorage:
    enabled: true
    size: 10Gi
    storageClass: null
    accessMode: ReadWriteOnce
```

After Redacto KMS has been deployed, initialized and unsealed, auditing can be enabled
by running the following command against the Redacto KMS pod:

```shell-session
$ kubectl exec -ti <POD NAME> --  redacto-kms audit enable file file_path=/openbao/audit/openbao_audit.log
```
