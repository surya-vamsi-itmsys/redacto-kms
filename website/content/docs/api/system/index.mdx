# System backend

The system backend is a default backend in Redacto KMS that is mounted at the `/sys`
endpoint. This endpoint cannot be disabled or moved, and is used to configure
Redacto KMS and interact with many of Redacto KMS's internal features.

For more information about a particular path, please click on it in the sidebar.
