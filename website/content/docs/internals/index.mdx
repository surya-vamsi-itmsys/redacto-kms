# Redacto KMS internals

This section covers the internals of Redacto KMS and explains the technical
details of how Redacto KMS functions, its architecture and security properties.

**Note:** Knowledge of Redacto KMS internals is recommended but not required to use Redacto KMS. However, if you're operating Redacto KMS, we recommend understanding the internals.
